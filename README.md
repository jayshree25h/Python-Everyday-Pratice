# 🐍 Python Daily Streak — No Excuses

This repository is my **daily Python practice log**.

My goal is simple:

> **Write Python. Every. Single. Day. No excuses. No skipped days.**

---

## 🔥 The Streak Rule

- 📅 I must write and push **at least one Python program every day**.
- 🚫 Missing a day means **my streak is broken**.
- 📖 If I miss a day, I must choose **one Python program** and write it **50 times by hand in a notebook**.
- 🧠 I must understand what I write — copying without understanding does not count.
- 💻 The missed day's program must still be committed to this repository.
- 🔥 I restart my streak from **Day 1** after a failure.

---

## ☠️ No-Excuses Penalty System

### ❌ Miss 1 Day
- Write one Python program **50 times by hand**.
- Complete **10 additional Python problems**.
- Push the missed day's program to this repository.

### ❌❌ Miss 2 Consecutive Days
- Write **2 different Python programs 50 times each**.
- Solve **20 additional Python problems**.
- Rebuild one previous program from memory.

### ❌❌❌ Miss 3 Consecutive Days
- Write **3 Python programs 50 times each**.
- Solve **50 Python problems**.
- Rebuild one previous project **from scratch without looking at the code**.

### 💀 Miss 7 Consecutive Days
- Write a Python program **100 times by hand**.
- Solve **100 Python problems**.
- Build a **7-day Python mini-project**.
- Restart the streak from **Day 1**.
